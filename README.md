# VFX Studio

Professional 2D game VFX production pipeline built around [EffectCraft](https://github.com/storytold/effectcraft).

> Bootstrap in progress: repository setup, pinned upstream installer, transparent spritesheet export and automated tests. EffectCraft's application is **not** vendored or compiled by this initial commit.

Source: https://github.com/storytold/effectcraft (MIT OR Apache-2.0).
